<details>
<summary><b>🪙 Kredit</b> · click to expand</summary>
<br/>

> **An on-chain OpenRouter.**

One API key reaches every major AI model through an OpenAI-compatible endpoint. The credits that pay for it come from what a wallet has done on Robinhood Chain, or from a top-up in USDG or ETH. Claims are signed by the server and written on-chain as receipts anyone can verify.

- 🔑 One key, OpenAI-compatible, every major model
- ⛓️ Credits from on-chain activity, or a USDG / ETH top-up
- 🧾 Server-signed claims written on-chain as verifiable receipts
- 🖥️ Ships with a dashboard, a playground, and a `kredit` CLI

**Stack:** Next.js 16 · Neon Postgres · Foundry contracts · Privy sign-in · Render

<details>
<summary><b>💸 Share-fees</b> · click to expand</summary>
<br/>

> **A wallet-native rewards desk.**

Qualifying token swaps earn credit at a published ratio: 50 bps of notional above a $250 floor. That credit converts either to USDG paid to the same wallet, or to a metered key for AI chat and image generation.

- 📈 Published reward ratio, no hidden math
- 💵 Cash out to USDG, or spend on metered AI chat and image generation
- 🔒 Every transaction hash pays once, no matter how many times it is scanned or claimed
- 👛 Ethereum and Solana wallets both sign in

**Stack:** TypeScript · Next.js · Solidity · Postgres · Replicate · Vercel AI Gateway

[![Repo](https://img.shields.io/badge/Repo-Share--fees-181717?style=flat-square&logo=github)](https://github.com/saurabh-sol/Share-fees)
